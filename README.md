# Task Manager App

Task management demo dengan CRUD, filter status, search, dan responsive layout.

## Features

- Create task
- Update task status
- Delete task
- Filter and search
- Responsive UI

## Tech Stack

- React.js
- Vite
- CSS

## Installation

```bash
npm install
npm run dev
```
